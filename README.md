# Desenvolvimento de Interfaces

Atividades, estudos e projetos da disciplina **Desenvolvimento de Interfaces**, do curso de Análise e Desenvolvimento de Sistemas (ADS) do UniCEUB — Brasília.

**Autor:** [Enzo Gurgel](https://github.com/enzogurgel)

## Conteúdo

| Módulo | Descrição |
|---|---|
| [01-html-css](01-html-css/) | Estudos de HTML5, primeiros códigos e um site em HTML e CSS |
| [02-javascript](02-javascript/) | Exercícios e mini-projetos em JavaScript (calculadoras e verificador de idade) |
| [03-ihc](03-ihc/) | Interação Humano-Computador: análise de interface e projeto de UX/UI em grupo |

## Tecnologias

HTML5, CSS3 e JavaScript.

## Como executar

Os projetos são páginas estáticas: não precisam de instalação nem de build.

1. Clone o repositório:
   ```bash
   git clone https://github.com/enzogurgel/DesenvolvimentoDeInterface.git
   ```
2. Abra o `index.html` do projeto desejado no navegador.

- Pastas em minúsculas, separadas por hífen, sem acento e sem espaço.
- Datas no formato AAAA-MM-DD.
- Cada projeto mantém os próprios arquivos (HTML, CSS, JS e imagens) na mesma pasta.
