## site-marvel-rivals

- `index.html` e `styles.css`: versão principal do site.
- `styles-nova-pagina.css`: variação da folha de estilos; contém uma declaração incompleta (`font-size: ;`) que o `styles.css` não tem.
- `versoes-anteriores/`: primeiras etapas do mesmo site, sem CSS (`index-sem-css.html`) e com CSS (`index-com-css.html`).
